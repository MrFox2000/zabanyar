# انتشار در کافه‌بازار و مایکت

اپ اندروید یک **پوستهٔ Capacitor** است که همان اپ وب را روی موبایل اجرا می‌کند
(`capacitor.config.ts` → `ir.zabanyar.app`). به این ترتیب آپدیت محتوا بدون APK جدید
منتشر می‌شود؛ ولی برای استور، APK/AAB امضاشده لازم است.

## چه چیزی آماده است

| مورد | مسیر |
|---|---|
| پروژهٔ اندروید | `android/` (Capacitor، appId `ir.zabanyar.app`) |
| آیکون ۵۱۲ | `store/icon-512.png` |
| تصویر شاخص ۱۰۲۴×۵۰۰ | `store/feature-graphic-1024x500.png` |
| اسکرین‌شات‌ها (۱۰۸۰×۱۹۲۰) | `store/01-…` تا `store/06-…` |
| سیاست حریم خصوصی | `/privacy` روی همان دامنه (لینک عمومی برای فرم استور) |
| نام پکیج | `ir.zabanyar.app` (بعد از انتشار قابل تغییر نیست) |

## کارهایی که فقط تو می‌توانی انجام بدهی

1. **حساب توسعه‌دهندهٔ کافه‌بازار**: ثبت‌نام با کد ملی، شماره موبایل به نام خودت و
   احراز هویت (پیشخان). مایکت هم حساب جدا دارد.
2. **رمز کی‌استور**: یک رمز انتخاب کن و در جای امن نگهش دار. بدون آن نمی‌شود نسخهٔ
   بعدی را منتشر کرد. (من کی‌استور را می‌سازم؛ رمز را تو می‌گویی.)
3. **تصمیم دربارهٔ پرداخت**: کافه‌بازار برای فروش محتوای دیجیتال، **پرداخت درون‌برنامه‌ای
   خودش (Poolakey / بازار-پی)** را الزامی می‌داند؛ لینک دادن به درگاه بیرونی (زرین‌پال)
   برای اشتراک داخل اپ خلاف قوانین است. دو مسیر:
   - **الف) توصیه‌شده:** اشتراک را داخل اپ با Poolakey بفروشیم (نیاز به کلید RSA از پیشخان)
   - **ب) محافظه‌کارانه:** اپ فعلاً رایگان با تبلیغ باشد، اشتراک فقط روی وب بماند و در
     اپ هیچ اشاره‌ای به خرید بیرونی نشود.

## APK آماده است

آخرین بیلد موفق CI: **`store/zabanyar-1.0.0.apk`** — ۳.۶۷ مگابایت، امضاشده با
APK Signature Scheme v2 (بررسی شد).

بیلد روی GitHub Actions انجام می‌شود (رونر خودش Android SDK دارد)، پس نیازی به نصب
Android Studio روی این کامپیوتر نیست:

- ورک‌فلو: `.github/workflows/android.yml`
- اجرای دستی: تب Actions → android → Run workflow
- خروجی: Artifact با نام `zabanyar-apk`

کلید امضا (این‌ها **هرگز** کامیت نمی‌شوند):

| فایل | مسیر |
|---|---|
| کی‌استور | `android/keystore/zabanyar-release.jks` |
| مشخصات امضا | `android/keystore/keystore.properties` |
| نسخهٔ پشتیبان رمز | `C:\Users\Cyber.s\Documents\zabanyar-keystore-password.txt` |

⚠️ اگر کی‌استور گم شود، دیگر نمی‌شود اپ را در بازار/مایکت آپدیت کرد. از این دو فایل
یک نسخهٔ پشتیبان بیرون از این کامپیوتر بگیر.

## دستورهای ساخت محلی (اختیاری، اگر Android SDK نصب شد)

```bash
npx cap sync android
cd android
./gradlew assembleRelease   # یا از CI استفاده کن
```

پس از امضا: `android/app/build/outputs/apk/release/app-release.apk`

## چک‌لیست قبل از ارسال به استور

- [ ] `versionCode` هر بار بزرگ‌تر شود (در `android/app/build.gradle`)
- [ ] امضا با کی‌استور خودمان، نه debug
- [ ] مجوزها حداقلی: فقط `INTERNET` (در `AndroidManifest.xml`)
- [ ] تست روی یک گوشی واقعی اندروید (باز شدن، صدا، RTL، دکمهٔ بازگشت)
- [ ] لینک حریم خصوصی: `https://zabanyar-kappa.vercel.app/privacy`
- [ ] کپشن‌ها و توضیحات بدون ادعای غیرواقعی
- [ ] رده‌بندی سنی: همه سنین (بدون خشونت/تبلیغ رفتاری)

## متن آمادهٔ صفحهٔ استور

**نام:** زبان‌یار — انگلیسی از صفر تا B2

**توضیح کوتاه (۸۰ کاراکتر):**
انگلیسی، بازی‌وار و پیوسته: ۱۶۸ درس از A1 تا B2 با آموزش، صدا و تمرین.

**توضیح بلند:**

زبان‌یار برای فارسی‌زبان‌ها ساخته شده و یک تفاوت اصلی دارد: هر درس روی درس‌های قبلی
ساخته می‌شود و خودش می‌گوید روی چه چیزی سوار است. بخشی از تمرین‌های هر درس از درس‌های
قبلی می‌آید تا هیچ‌چیز فراموش نشود.

• چهار سطح کامل: A1، A2، B1 و B2 — ۴۲ واحد و ۱۶۸ درس زیر ۴ دقیقه
• هر درس با کارت‌های آموزش شروع می‌شود: صدا → کلمه/حرف → جمله → نکتهٔ کوتاه گرامر
• ۸ نوع بازی: شنیداری، چیدن جمله، جورچین، پیدا کردن خطا، دور سرعت و…
• ۳ جان، کمبو، ستاره، نبرد پایانی هر واحد و صندوق روزانه
• «دفتر من»: همهٔ کلمه‌ها، جمله‌ها و نکته‌ها با جست‌وجو و تلفظ
• «ضعف‌های من»: هر جایی که اشتباه کردی، همان درس را نشانت می‌دهد
• بدون ثبت‌نام؛ پیشرفت روی گوشی خودت می‌ماند

**کلمات کلیدی:** آموزش انگلیسی، زبان انگلیسی، یادگیری انگلیسی، لغت انگلیسی، گرامر،
آیلتس، انگلیسی از صفر، بازی آموزشی
